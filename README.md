
# Kindle WhatsApp KOReader Plugin

A WhatsApp plugin project for Kindle devices running KOReader.

## Features
- WhatsApp integration for Kindle
- Designed for KOReader
- Supports plugin packaging through GitHub Actions
- Automated ZIP build and download

## Build

1. Open the **Actions** tab.
2. Select **Build Kindle WhatsApp Plugin**.
3. Click **Run workflow**.
4. Wait for the build to finish.
5. Download the ZIP file from **Artifacts**.

## Installation

1. Extract the downloaded ZIP.
2. Copy the `.koplugin` folder into:

   `koreader/plugins/`

3. Restart KOReader.
4. Open the KOReader Plugins menu.

## Compatibility

Target device: Kindle Paperwhite 11th Generation.

Requires KOReader.
